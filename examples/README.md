# Protocol examples

These examples are generated by `agent-clearance-generate` from the reference loop. They illustrate one bounded availability-search flow.

| File | Object |
|---|---|
| [discovery.json](discovery.json) | `/.well-known/agent-clearance` |
| [challenge.json](challenge.json) | `401` challenge body |
| [mandate.json](mandate.json) | Origin-scoped mandate |
| [presentation.json](presentation.json) | Presentation JSON body |
| [decision.json](decision.json) | Origin decision with critical obligations |

The presentation HTTP Message Signature is not in `presentation.json`. It belongs on the presentation POST. Signed HTTP fixtures live under [`conformance/vectors/`](../conformance/vectors/).

Strings representing keys and signatures are from documented test-key seeds. They are not production credentials and MUST NOT be copied into real systems.

Do not treat these files as complete negative coverage. The conformance suite is the test.
