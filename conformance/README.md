# Conformance vectors

These vectors are generated by `agent-clearance-generate` and checked by `agent-clearance-conformance`.

They are not production credentials. Signatures use test keys derived from the documented seed `agent-clearance-test-key-do-not-use:`.

A vector passes when the reference origin returns the expected decision and reason codes. Independent implementations should consume `conformance/vectors/manifest.json` and fail closed on the negative cases even if they use different code.
